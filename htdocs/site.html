This site is dead. UCanAccess is not.

You are on the old SourceForge home of UCanAccess. Nothing here gets updated anymore. Its last release, 5.0.1, dates back to January 2021.

UCanAccess is an open-source, pure Java JDBC driver that reads and writes Microsoft Access databases (.mdb and .accdb) without ODBC. Development continues on GitHub. Since moving there, UCanAccess has shipped 10 releases with current Jackcess and HSQLDB versions and support for Java 11, 17 and 21. The current version is 5.2.0.

Go to UCanAccess on GitHub
  • Releases and downloads
  • All versions on Maven Central
  • Documentation
  • Jackcess, the maintained fork UCanAccess builds on
  • HSQLDB, the SQL engine behind UCanAccess
